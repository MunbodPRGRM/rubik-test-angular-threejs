# 🎲 เว็บแอปพลิเคชันรูบิก 3 มิติ (3D Interactive Rubik's Cube)

โปรเจกต์เว็บแอปพลิเคชันรูบิก 3 มิติที่สามารถโต้ตอบได้ สร้างขึ้นด้วย **Angular**, **Three.js**, และ **GSAP** ผสานรวมอัลกอริทึมคณิตศาสตร์แบบ 3 มิติเพื่อให้การควบคุมเป็นธรรมชาติที่สุด

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen.svg)](https://rubik-3d-test.web.app/)

> **🌍 ลองเล่นโปรเจกต์จริงได้ที่นี่:** [https://rubik-3d-test.web.app/](https://rubik-3d-test.web.app/)

## ✨ ฟีเจอร์หลัก (Features)

- **การโต้ตอบ 3 มิติอิสระ 360 องศา (Free Rotation):** หมุนกล้องดูรอบก้อนรูบิกได้ทุกทิศทางแบบไร้ข้อจำกัดด้วย `TrackballControls` สามารถตีลังกากล้องพลิกแพลงมุมมองได้ดั่งใจเหมือนจับรูบิกของจริง
- **ระบบควบคุมการลากอัจฉริยะ (Camera-Relative Drag Controls):** คำนวณทิศทางการปัดนิ้วอิงจากมุมมองกล้องปัจจุบัน (ผ่านสมการคณิตศาสตร์ 3D เวกเตอร์) ทำให้ไม่ว่าผู้ใช้จะหันมองรูบิกจากมุมกลับหัวหรือมุมใด การปัดนิ้วก็จะหมุนชิ้นส่วนไปในทิศทางที่ถูกต้องแม่นยำ 100%
- **กราฟิกสมจริง (Realistic Rendering):** ดีไซน์ชิ้นส่วนแบบขอบโค้งมน (`RoundedBoxGeometry`) แกนในสีดำ พร้อมสติกเกอร์สีรับการตกกระทบของแสงไฟสปอตไลท์ (`MeshStandardMaterial`) ให้ความรู้สึกเหมือนพลาสติกของแท้
- **แอนิเมชันลื่นไหล:** ใช้ GSAP ในการทำแอนิเมชันหมุนชิ้นส่วนแต่ละชั้นให้ดูนุ่มนวลและสม่ำเสมอ
- **สับเปลี่ยนและเริ่มใหม่ (Shuffle & Reset):** มีอัลกอริทึมในตัวสำหรับหมุนสุ่มสับเปลี่ยนสีรูบิกด้วยความเร็วสูง และมีปุ่มรีเซ็ตเพื่อกลับคืนสู่สภาพที่แก้เสร็จแล้ว
- **รองรับทุกขนาดหน้าจอ (Responsive Design):** ปรับขนาด Canvas 3 มิติและสัดส่วนมุมกล้องให้พอดีกับหน้าจอ (PC, Tablet, Mobile) โดยอัตโนมัติ

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Framework:** [Angular](https://angular.io/) (TypeScript)
- **3D Graphics:** [Three.js](https://threejs.org/)
- **Animation Engine:** [GSAP](https://greensock.com/gsap/) (GreenSock Animation Platform)

## 🏗️ โครงสร้างของโปรเจกต์ (Architecture)

โปรเจกต์นี้ใช้หลักการแยกส่วนการทำงาน (Separation of Concerns) อย่างเคร่งครัด เพื่อให้โค้ดเป็นระเบียบและคงประสิทธิภาพสูงสุด:

- `EngineService` **(แกนหลัก):** ทำงานอยู่นอก Angular Zone (`NgZone.runOutsideAngular`) เพื่อป้องกันปัญหาคอขวดด้านประสิทธิภาพ ทำหน้าที่จัดการ `WebGLRenderer`, `Scene`, `Camera`, ลอจิกการตรวจจับของ Raycaster, และการคำนวณตำแหน่ง 3 มิติ
- `RubikCanvasComponent` **(ส่วนแสดงผล):** Component น้ำหนักเบาที่ทำหน้าที่แค่เชื่อมต่อแท็ก HTML `<canvas>` เข้ากับ `EngineService`
- `ControlsPanelComponent` **(ส่วนอินเทอร์เฟซผู้ใช้):** ส่วนควบคุม UI ที่ซ้อนทับอยู่ด้านบน เพื่อใช้สั่งการทำงานระดับสูง เช่น การสับเปลี่ยนสีและการเริ่มใหม่

## 🧠 ลอจิกการทำงานที่สำคัญ (Core Logic Highlights)

- **Vector Cross Product:** แก้ปัญหาทิศทางการลากเมาส์สลับทิศ (Camera Direction Bug) โดยการหา Cross Product ระหว่าง "หน้าสัมผัสของรูบิก (Face Normal)" กับ "ทิศทางที่ลากบนหน้าจอ (Drag Vector)" ทำให้ได้แกนหมุนที่ถูกต้องตามมุมมองกล้อง
- **Matrix Attachment:** ใช้ระบบ `.attach()` ของ Three.js ในการจัดกลุ่ม 9 ชิ้นส่วนเข้าด้วยกันชั่วคราวเพื่อเป็นแกนหมุน (Pivot) ช่วยรักษาพิกัด Quaternion ของชิ้นส่วนไม่ให้เพี้ยนหลังจากการหมุนซ้อนทับกันหลายแกน
- **Sticker Mapping System:** จำลองการสร้างก้อนพลาสติกสีดำ และคำนวณการแปะ `PlaneGeometry` (สติกเกอร์สี) เฉพาะหน้าต่าง ๆ ที่หันออกด้านนอกเท่านั้น เพื่อความสมจริงระดับสูงสุด
